# 𝗛𝗲𝗹𝗹𝗼！

**全栈工程师 · 嵌入式开发者 · 边缘 AI 实践者**

专注**电力 / 能源行业**软件研发，覆盖从端侧设备（ZYNQ / RKNN / Raspberry Pi）到云端服务（Docker / Kubernetes）的完整链路，目前在探索把 **LLM 与边缘 AI** 带入电力物联网场景。

## 🤖 AI

- **LLM 应用**：基于 OpenAI / Claude / Ollama 构建应用与 Agent 工作流
- **边缘推理**：RKNN（Rockchip NPU）+ OpenCV，模型部署到端侧设备
- **训练与生态**：PyTorch / TensorFlow / Hugging Face

## ⚡ 电力通信协议

**IEC 60870-5-101 / 104** · **IEC 61850** · **Modbus** · **OPC UA** · **DL/T 645** · **DL/T 698**

面向配电自动化、变电站与智能电表的数据采集与系统互联。
